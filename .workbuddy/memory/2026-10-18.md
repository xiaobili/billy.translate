# 2026-10-18

## billy.translate 0.2.2 — 翻译表格导致 quickshell 崩溃（已修复）

- 现象：`ALT+SHIFT+D`（rich 模式）翻译含 Markdown 表格的内容时，quickshell 段错误，
  栈为 `QSGBatchRenderer::Renderer::prepareAlphaBatches`。
- 复现：调用日志里的 `report.txt` + 上次请求体 `~/.local/state/omarchy/translate/body.json`
  （22 行两列表格）。用 `QT_QPA_PLATFORM=wayland /usr/lib/qt6/bin/qml` 跑 420px 宽的
  `Text.MarkdownText`，按 100ms 追加文本 → 稳定 SIGSEGV；`coredumpctl` 取 quickshell core
  对比，栈与偏移完全一致。offscreen 平台不建渲染器（`GraphicsInfo.api == 0`），测不出来。
- 根因：Qt 的 Markdown 表格是 `QTextTable`，**第二次布局**（流式每 100ms 改文本）就会
  损坏场景图。一次布局没事、PlainText 没事、无表格的 Markdown 没事，已逐项验证。
- 修法：`Translate.flattenTables()` 在渲染前把表格摊平成列表项（表头也作为首项，
  分隔行丢弃，代码块内不动），其余 Markdown 不变；复制仍取原始 Markdown。
  Bubble 的 `displayText` 改为整段一次 transform（表格行需要看下一行，前缀缓存失效），
  2.3KB 文本实测 0.16ms/次。
- 测试：`tests/translate.test.js` 增 11 条 flattenTables 用例（93/93 通过）；
  把 flattenTables 改成恒等后降为 86/93，证明守卫有效。
- 已本地提交 `32ee8af`（未 push）。

## 0.3.0 — 按需求改为保留表格线框渲染

- 用户不要列表形式，要保留表格框线。新增 `Table.qml`（GridLayout + 边框格子，
  表头加粗，不依赖 qs.Commons，可独立运行/截图）；`Translate.splitBlocks` 把译文
  切成 md/table 块，Bubble 按 index 渲染（流式只更新绑定不重建 delegate）；
  列宽 = 各列最宽单元格估宽（CJK 1em / 其他 0.55em），最小 68px、单列上限 60% 行宽，
  像素取整差额补到最宽列。
- `flattenTables` 保留为安全网（splitBlocks 漏掉的表格降级为列表），崩溃无回归路径。
- 验证：wayland 流式 harness 3/3 干净退出（旧路径 3/3 SIGSEGV）；截图确认线框与
  词边界换行；107/107 单测；热加载无告警。提交 `86f0c2e`（未 push）。
